## 4-5 실습 전 준비

`4-5. 모델 서빙 프레임워크로 모델 서빙하기` 실습에서는 Gemma 계열 모델을 사용합니다.  
해당 모델은 Hugging Face에서 사용 권한 승인이 필요하므로, 실습 전에 미리 신청해 주세요.

- 신청 링크: https://huggingface.co/google/gemma-3-1b-it
- 승인까지 약 1~2시간 소요될 수 있습니다.
- 승인 후 Hugging Face 토큰을 발급받아 실습에서 사용합니다.
